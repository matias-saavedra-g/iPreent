# iPreent brand

| File | Use |
|---|---|
| `icon.svg` | App icon on every platform (Android launcher, Windows exe/Start, macOS, Linux .desktop). 512×512 master. |
| `icon-small.svg` | 16–32 px: favicon, tray / menu bar, Windows taskbar small sizes. Fewer details so it stays readable. |
| `icon-mono.svg` | One color, uses `currentColor`: Android notification icon, macOS menu bar template, print-dialog glyphs. |
| `logo.svg` | Icon + "iPreent" wordmark for README, About screens, store listings. |

**Idea:** a cat-eared thermal printer (a nod to the cat-face printers it was made for) printing a receipt with an
"i" and lines of text. The torn zigzag edge says "thermal paper" even at small sizes.

**Colors**
- Baby blue `#89CFF0` (primary) · deeper blue `#4A90B8` (slot, wordmark, pressed states). Was teal `#0B6770` until 2026-10-20.
- Ink `#1B1B1F` · Paper `#F7F7F4` / `#FFFFFF`

**Type:** IBM Plex Sans Bold for the wordmark ("i" in ink, "Preent" in deeper blue). IBM Plex Sans/Mono in the UI.
The wordmark is live text: convert it to outlines before using it anywhere the font might be missing.

**Rules:** keep the rounded-square background on app icons; don't recolor the paper; leave clear space of at
least one ear-height around the logo.
